# 第五页：当声音成为音乐

本版在已完成的四课科普＋KEY3双声道波形/1024点FFT版`a7b499d`基础上增加第五课。依据用户的《第五页提示词.md》，实现“音乐欣赏＋实时声音可视化”，不是WAV背景音乐播放器。

## 1. 直接使用

1. 下载本版bit：`../../src/td_project/HDMI1.4b_Transmitter_v1.0_Runs/phy_1/HDMI1.4b_Transmitter_v1.0.bit`。
2. 备份TF卡后，按原要求准备FAT32、连续存放的五张BMP。源文件在`bmp/`，顺序01至05；新文件是`05_melody.bmp`，960×720、24-bit非压缩、4:3，沿用双线性缩放至640×480。
3. 使用KEY2逐页切到第五页，或者KEY4打开自动轮播。第五页进入后从头播放完整旋律，KEY3可同时显示/隐藏实时波形和FFT频谱；默认隐藏，不强制打开。
4. WAV仅供电脑试听，不复制到TF卡。FPGA内部实时合成音频；只放WAV不会播放。
5. 实板确认后再烧写Flash并做断电重启。此次只生成文件、运行软件仿真和TD构建，没有写物理TF卡或烧写Flash。

如果仅下载新版bit、仍使用只有四张图片的卡，不会凭空得到第五页，还可能扫描至原64MiB上限才完成。应同时更新为本版五图素材。不可在含有旧BMP残留头的卡上仅删除/覆盖文件后就假定物理扫描顺序正确。

## 3. 按键与播放边界

| 板上按键 | 保持的功能 |
|---|---|
| KEY1 / A2 | 复位，分析面板恢复隐藏 |
| KEY2 / B2（旧信号key1） | 短按下一页；长按亮度 |
| KEY3 / B1 | 一次同时显示时域＋FFT，再按同时隐藏；长按/松开不重复切换 |
| KEY4 / C1（旧信号key2） | 短按自动轮播；长按对比度 |
| KEY2+KEY4长按 | 恢复默认显示参数 |

第五页的旋律在图片黑场换缓冲、实际页面编号提交后启动；不是在“请求加载第五张图”时提前播放。与前四课相同，音频从黑场/淡入开始跟随目标页，完整亮度时已播放少量起始音。

进入第五页播放一次完整8秒，随后保持静音，不把第二轮旋律播放一半再被自动轮播切断。离开再返回时从头重播。自动轮播保留原“完全显示后8秒”的停留计时，同时额外检查旋律完成状态；若音乐尚未结束，计数器停在阈值等待，不回卷，也不提前加载下一图。

手动切图仍立即响应，允许用户主动中断旋律。这里“保证完整播放”针对自动轮播，不限制原有手动操作。关闭分析面板不停止音频、FFT或采集。

## 4. 旋律与算术实现

使用已有25MHz视频域的32-bit DDS和256相位正弦查表。音频仍由原有理数时钟使能生成，平均48kHz、24-bit双声道，经原I2S_receiver解码后同时送HDMI、时域波形和FFT。没有新增时钟、音频文件解析或外接硬件。

原创C大调四小节短句，120BPM：

`C4 E4 G4 A4 G4 | E4 D4 E4 G4 | A4 C5 B4 G4 | F4 E4 D4 C4`

共17个音符，以八分音符0.25秒/12000个采样为单位，总32单位、384000对立体声采样，恰好8秒。第一小节的E4/G4及最后小节的F4/E4为八分音符，最后C4为二分音符，其余为四分音符。左右声道输出同一旋律，不混入前四课音源。

每条音符记录包含相位增量、持续单位和Q6音量。相位增量为`round(frequency * 2^32 / 48000)`，采用十二平均律音高。音符间相位重新起算；256采样（5.33ms）渐入、512采样（10.67ms）渐出，最后采样为0，降低切换爆音。

音量计算：`amplitude=(signed_sine16 * gain_q6 * 60) >>> 6`，再乘0..64包络并算术右移6。加法/乘法使用明确有符号扩展，最大峰值不超过1,966,020，低于24-bit满幅的1/4，不需要削顶或回卷。每一步右移截断行为与独立PCM参考逐位比较。

前四页的音源函数和参数保持原数值；仅页面类型从2位扩为3位。`lesson_step`仍是前四页的2位阶段编号，旋律内部另用5位音符编号，不复用造成溢出。

## 5. 图像管理、跨时钟与缓存

- `sd_card_bmp.v`增加第五个文件起始扇区记录，页面编号3位、发现数量3位、循环0→1→2→3→4→0。
- `bmp_bilinear_reader.v`本来支持3位扫描数量，不改其像素算法；顶层扫描目标从4改为5。
- `video_fade_transition.v`的图音绑定载荷扩为3位，仍通过稳定载荷＋toggle同步，黑场同时提交页面与帧缓冲。
- **SDRAM缓存仍为两帧，地址和FIFO结构不变。** 两位buffer编号没有被扩为“五帧”。新增图片不会常驻SDRAM。
- `melody_complete`为视频域保持电平，跨到100MHz SD域经过三级同步；只用于第五页自动推进门控，不把单拍脉冲跨域。原手动切换优先级保持不变。
- KEY3、原时域模块、FFT算法/系数/绘图模块及视频流水线延迟均未修改。

## 9. 实板验收与赛题状态

基本功能、扩展1～5和本次第五页均已在同一工程实现并通过本版工具构建/回归；基础要求中的Flash上电自启、物理长稳以及第五页实际扬声器听感仍为**部分完成、待实机验收**，不能写成已全部上板通过。

1. 用新版bit＋五图TF卡，确认01～05顺序、方向、颜色，原四课声音不变。
2. 第五页完整听8秒，首尾无明显爆音；结束后静音，返回第五页重新从C4播放。
3. KEY3两次操作分别同时显示/隐藏两个分析区域，观察旋律的频谱峰和波形变化；不打开时正常看第五页音符图。
4. 自动轮播第五页不截断首轮旋律；KEY2仍可主动提前离开，亮度/对比度、字幕/Logo和转场均正常。
5. 连续轮播至少30分钟、按键至少100次、10次冷启动；检查热插拔显示器后恢复、无花屏/挂起/音频断续。
6. 全部通过后再固化Flash并断电验收。此次未操作物理卡、开发板下载或Flash。

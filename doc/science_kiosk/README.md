# 看得见的声音：FPGA声学科普展示终端

本目录是当前科普主题版本的使用入口。四张BMP提供中文讲解，FPGA按实际显示页合成相应的24-bit双声道教学音频，KEY3可打开实时波形辅助观察。没有改成WAV文件播放器，也不需要外接音频采集硬件。

## 一、下载与素材

- 工程：`../../src/td_project/HDMI1.4b_Transmitter_v1.0.al`。
- 新版bit：`../../src/td_project/HDMI1.4b_Transmitter_v1.0_Runs/phy_1/HDMI1.4b_Transmitter_v1.0.bit`。
- `bmp/`：四张24-bit、非压缩、4:3 BMP，按01～04顺序使用。
- `audio/`：四段8秒、48 kHz、24-bit立体声WAV，供电脑试听。音频算法与FPGA对应，不需要复制到TF卡。
- `preview/overview.png`：四张图片总览。图片顶部和底部特意留给已有Logo、计时、BRI/CON及滚动字幕。
- `science_tf_64MiB.img`：可选的64 MiB FAT32整卡镜像，含四张连续存储、顺序确定的BMP。
- `science_materials.zip`：图片、试听音频、预览及本说明的便携包，不含整卡镜像。
- `manifest.json`：图片尺寸对应文件、实际扇区位置和卡镜像SHA256。

请同时使用本次bit和四张主题图片。仅更换图片、继续用旧bit，不会获得对应的教学音频。

## 二、四课内容

每课音频按四步循环，每步1秒、完整循环4秒。自动轮播在一页完整显示后等待8秒，再加载下一页并转场；加载和转场时间另计。

| 顺序 | BMP源尺寸 | 音频内容 | 观察重点 |
|---|---|---|---|
| 01 音高与频率 | 640×480 | 正弦波220→330→440→660 Hz | 频率升高，5.33 ms窗口内波形变密 |
| 02 响度与幅度 | 800×600 | 440 Hz正弦波，峰值1/4→1/2→1→1/2 | 周期不变、幅度变化；听感并非线性比例 |
| 03 音色与波形 | 1024×768 | 440 Hz正弦→三角→方波→正弦 | 相同频率和峰值，不同谐波结构与音色 |
| 04 左右声道 | 1280×960 | 仅L→仅R→双声道→双声道；L=440 Hz，R=660 Hz | 声道静音时该轨迹为平线，双声道时疏密不同 |

音频使用64采样的起落包络，降低阶段切换的突变。峰值不超过1,966,020，低于24-bit满量程的1/4。第三课不同波形虽同峰值，RMS及主观响度仍可能不同，不应解释为严格等响。

四张BMP尺寸不同，但都保持4:3，加载时沿用双线性拉伸至640×480，不产生纵横比例变化。按KEY3后，实时波形覆盖下半部示意图；关闭后可完整阅读静态图示。原HOLD提示行仍已删除。

## 三、按键和原功能

| 板上按钮 | 管脚 / 旧信号名 | 功能 |
|---|---|---|
| KEY1 | A2 / `rst_n` | 复位，回到第一课，波形默认隐藏 |
| KEY2 | B2 / `key1` | 短按下一课；长按调图像亮度 |
| KEY3 | B1 / `key3` | 短按一次显示波形，再按一次完全隐藏；长按不连翻 |
| KEY4 | C1 / `key2` | 短按开关自动轮播；长按调图像对比度 |

同时长按KEY2、KEY4恢复默认亮度/对比度。KEY2/KEY4的原短长按识别、连调、防抖及管脚不变；参数调节仅影响图片，不改变教学音量。波形默认隐藏、隐藏时音频仍播放。

## 四、TF卡准备：不会自动操作你的卡

本次只生成工作区文件，没有格式化、清空或写入任何物理TF卡。旧`doc/convert/sync_to_sd.py`含清空旧文件逻辑，本次未运行，不建议直接对存有资料的卡执行。

### 普通复制方式

1. 先备份卡上资料，使用空白FAT32卡或由你确认后完整格式化的卡。
2. 只将`bmp/`内四张BMP按01、02、03、04顺序复制到根目录，不混入旧图片。
3. 安全弹出后插入开发板。

当前FPGA按物理扇区扫描，最多4张、只在前64 MiB范围找文件头，且要求文件连续存储。因此普通复制的物理顺序不是由文件名保证的；若旧卡有残留BMP头、碎片或顺序异常，请使用下面的确定性镜像方式。

### 可选镜像方式

由你使用可信的磁盘镜像写入工具，将`science_tf_64MiB.img`写入确认无误的TF卡。**写入整卡镜像会覆盖目标卡的分区和数据，务必先备份并核对目标设备。不要把.img当普通文件复制到卡里。** 镜像形成约63 MiB FAT32分区，大容量卡剩余空间暂不使用，这是正常现象。

镜像内按顺序为`01PITCH.BMP`、`02LEVEL.BMP`、`03TIMBR.BMP`、`04STEREO.BMP`，起始扇区为4067、5868、8681、13290，全部连续存储。镜像只含BMP和FAT32元数据，试听WAV不在卡中。

## 五、工程修正与同步关系

### 视频行尾修正

`video_rgb_to_axis_640x480.v`原计数器在行首写0，导致第640个像素处理时旧计数仍为638，未产生TLAST。本版在行首将下一像素计数置1，保证TLAST与每行最后一个像素一同寄存。两帧测试检查614400个RGB像素、960个行尾和2个帧首。

### SDRAM时序风险处理

- 原125 MHz、180°移相配置仅提供4 ns半周期预算，而硬SDRAM模型的读出及封装延迟使最差路径出现-6.699 ns。
- 新建用户HDL `science_sys_pll.v`，保留原1 GHz VCO和100 MHz SD输出，仅将SDRAM两个输出改为40 MHz、0°/180°，提供12.5 ns半周期预算。原厂PLL包装文件及加密SDRAM源码不改。
- `global_def.v`同步改为25 ns周期，刷新计数改为1249，按0～1249计数保持1250×25 ns=31.25 us的刷新周期，而不是直接降频后延长刷新间隔。
- 明确FIFO占用数为9位，并在连接10位控制端口时显式补0，消除仿真中高位悬空造成的等待问题。
- 给读请求应答加两级视频域同步；读写突发启动前等待SDRAM初始化/刷新忙状态结束。
- 没有用新增false_path屏蔽SDRAM违例。视频25 MHz、SD 100 MHz、HDMI串行125 MHz均保持不变。原有厂商视频/串行时钟分组保留。

### 图音页码绑定

SD域将目标页码作为稳定payload随转场toggle发送；视频域先同步payload，再在黑场换读缓冲时同时提交页码。新音源在下一个双声道I2S帧边界复位该课的相位、阶段和包络，因此音频随实际换页，不随按键抖动或尚未写完的图片提前变化。

`science_audio_i2s.v`在25 MHz视频时钟中以有理数累加器产生平均12.288 MHz的时钟使能，再按每256个使能产生一对PCM，平均采样率为48 kHz，不受原12.295 MHz音频PLL偏差影响。这里是clock-enable而非新建逻辑时钟。数据仍先串行为I2S，再由原`I2S_receiver`解码给HDMI、ACR和波形模块。

旧音频PLL仅保留既有的启动lock/复位作用，不再决定音频采样速率。板载50 MHz晶振的实际误差仍会等比例作用于所有派生频率。

## 八、上板验收与赛题边界

1. 先用JTAG下载新版bit，不急于覆盖Flash稳定版；准备以上四张BMP，连接有音频播放能力的HDMI_B显示设备。
2. 首课应显示“音高与频率”，听到220/330/440/660 Hz循环。KEY3开启波形，观察疏密变化，再按一次隐藏。
3. KEY2依次切换四课，检查音频在黑场换页时跟随；第二课振幅改变，第三课形状改变，第四课出现单侧平线与双侧不同频率。
4. 左右声道演示最好使用立体声HDMI接收设备或耳机；若设备混成单声道，空间方向不明显，但仍能观察L/R曲线。
5. 检查KEY2/KEY4长按调亮度/对比度、双键恢复默认、KEY1复位及KEY3开关均正常，HOLD提示没有重新出现。
6. KEY4开启轮播，确认每课完整显示约8秒后再进入下一课；至少运行30分钟，检查花屏、撕裂、音频中断或冻结。
7. 通过后再按原板卡流程固化Flash，验证脱离PC断电重启。当前没有代替用户进行硬件下载、写TF卡或Flash烧写。

基础1～3和扩展1～5已在同一工程中实现；扩展5采用赛题允许的波形路线，未实现硬件FFT频谱。固化、实际音视频效果、长稳运行仍待板测，不能仅凭工具通过宣称基础4完全验收。

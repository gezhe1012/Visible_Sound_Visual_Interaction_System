# 大自然的声音：启动开场页

基线：`7b58cea`，原五张教学 BMP + 第六页实时人声。新增内容只在上电/复位后的开场阶段运行，不改变原教学页编号、顺序、环回关系。

## 功能边界

| 项目 | 开场页 | 原六个教学页 |
|---|---|---|
| 短按切图键（顶层 key1，板载 KEY2） | 下一张风景图 | 原下一页逻辑 |
| 短按轮播键（顶层 key2，板载 KEY4） | 开/关轮播，每图约 8 秒 | 原轮播逻辑，继承开场的轮播状态 |
| 板载 KEY3 | 下一张风景图，不控制分析面板 | 原时域波形 + FFT 同开同关 |
| 亮度、对比度、组合键、复位 | 保留原有控制模块；参数连续保留 | 不变 |
| HDMI_A 副屏 | RGB 黑屏；时序、TMDS、DDC 继续运行 | 原内容自动恢复 |
| Logo、时间、参数提示、两端律动 | 保留；字幕为“大自然的声音” | 原每页字幕及布局 |

第四张风景图展示后，再按一次切图键或等待轮播计时，进入原教学第一页。正常教学轮播不会再返回开场；复位后重新展示开场。最终切图的 KEY3 若一直按住，须先松开再按，才能控制教学分析面板，避免同一次按压触发两个页面。

## 实现结构

```text
现有 TF/SPI + BMP 双线性读取器
  ├─ 启动扫描：按 ANLINTRO 标记及 ID 找齐四张素材
  ├─ 逐张预载：SDRAM bank 0/1/2/3，各 307200 个 32-bit 字
  └─ 播放阶段：复用 SD 总线读取所选图片内绑定的 RIFF/WAV
                    ↓ 512×16 异步 FIFO
              48kHz 采样节拍 → 单声道复制为双声道 24-bit PCM → 原 HDMI/ACR

四张 SDRAM 图片 → 逐像素层级/坐标映射 → 原读 FIFO / 图像调整 / OSD → HDMI_B
开场退出       → SD 扇区结束、黑场交接 → 原五文件扫描、双缓冲和六页教学
```

第一张全屏；后三张以 512×384、原比例缩小到 80% 的卡片叠加，分别从左、右、上方进入，动画 32 帧。旧卡片保留为下层。每个输出像素只读一个最终可见的图层，不增加片上整帧缓存或双路视频读取。前景在导出时双线性缩小，放在 640×480 画布的左上 512×384 区域；原教学图片的加载期双线性缩放不变。

现有厂商 SDRAM 控制器使用 **BL4 四字突发**，不能用任意跳跃的逐像素地址冒充单字读接口。因此图层左右边界、横向位移均按 4 像素对齐，每组四个输出像素严格对应四个连续、4 字对齐的 SDRAM 地址。`tb_nature_sdram_contract` 使用真实厂商加密控制器和命令级存储模型验证对齐读取；其反例确实检出不安全的逐像素 5/4 缩放地址。这不是仅在理想随机访问 RAM 模型上验证。

视频域、100MHz SD 域和 40MHz 存储域之间使用同步器、稳定载荷和 FIFO。几何参数经两级同步后，只在原读 FIFO 的帧复位窗口锁存；读请求与地址按同一三级流水对齐，读尾保护相应增加三周期。原页面走原地址旁路，保留原十周期读尾保护。

新增同步器的**第一级输入**使用有界的 datapath-only 最大延迟约束：几何 20ns、SD 事件/载荷 20ns、视频握手 39ns；不对第一级作同步边沿的建立/保持假设。后续同步级和快照路径仍完整分析，不新增全时钟域 false path / 多周期约束。WAV 图片 ID 还在请求同步后额外等待三个 SD 时钟，保证稳定载荷晚于请求消费。

TD 会跨层次合并物理 Slice，第一级寄存器的物理名称可能变成相邻算术单元，不能只凭名字约束。最终约束以**源时钟 + 稳定载荷源信号 + 目标时钟**共同限定，只覆盖第一个跨域采样点；第二级由目标时钟发起，不匹配该路径。FIFO Gray 指针和视频像素不经过这些指定载荷。原读请求/读缓冲索引也以有限 20ns 输入界限约束其首级，不再依赖原有易失配的首级名称 false path。BMP 标记判断寄存化，不把新增比较直接串入 100MHz 状态跳转路径。SDC 绑定和实际物理同步链均需核验，不能只凭“bit 已生成”放行。

## TF 素材

导出目录：`output/nature_intro_tf/`。

1. 保留 TF 卡上已经验收的五张教学 BMP。
2. **仅新增 `INTRO1.BMP`～`INTRO4.BMP`**；不要复制未打包的原始风景 BMP，也不要把教学图片重命名或调整先后顺序。
3. 独立 `INTRO1.WAV`～`INTRO4.WAV` 供试听/留档，板上不依赖这些独立 WAV 文件。音频已经逐字节嵌入对应 BMP 的尾部，由 FPGA 实际读取，不是 DDS 代替。
4. 延续原工程限制：合法文件连续占据物理扇区，起始及有效数据位于扫描窗口前 64MiB。工程未新增 FAT 链遍历器；普通复制若造成碎片或落在扫描窗口之外，可能无法识别。不要覆盖已验证卡，建议先使用备份卡验证。

打包格式为合法的 640×480、24-bit 未压缩 BMP：`bfOffBits=128`，54～71 字节为应用标记/图片 ID/WAV 相对扇区/采样数；首图像素无损复制，后三张导出为上述预缩放卡片画布。BMP 像素后按 512 字节对齐追加完整 RIFF/WAV。WAV 为原创合成旋律，48kHz、16-bit 单声道、8 秒，头部用 JUNK 块将 PCM 起点对齐到下一扇区，送入 HDMI 前左移 8 位并复制到左右声道。

生成/校验：`tests/export_nature_assets.py`。`manifest.json` 保留原 BMP 及输出文件 SHA-256、采样信息、原文件未改动和各前景缩放区域。原始四张 BMP 不改动；参考图内原有水印不处理。

旧卡缺少完整的四张标记图片时，扫描结束后跳过开场进入教学，不会将普通教学 BMP 误当作风景。扫描前 64MiB 需要一定启动时间；此期间主屏仅显示原 OSD，副屏黑屏。

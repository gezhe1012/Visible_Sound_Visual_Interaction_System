# KEY3 声音分析面板：时域波形 + 1024点双声道FFT

本版建立在声学科普版 `769e389` 之上。原四张BMP、对应音频算法、TF卡内容、Logo、计时、BRI/CON数值和底部滚动字幕均不变；不用重新制卡。只需重新下载本版bit。

## 1. 操作与屏幕布局

- 上电/复位：面板隐藏，正常阅读教学图片。
- KEY3第一次稳定按下：在下一视频帧同时打开频谱和时域波形。
- KEY3第二次稳定按下：在下一视频帧同时隐藏两者，恢复教学图片。
- 长按不重复触发，松开不切换；继续使用20ms防抖。
- KEY1复位；KEY2短按下一课、长按亮度；KEY4短按自动轮播、长按对比度；KEY2+KEY4长按恢复显示参数。没有新增管脚或改变手势。

| 区域 | 640×480像素坐标 | 内容 |
|---|---|---|
| 原有顶部OSD | 保持原范围 | ANLOGIC、时间、BRI/CON数值 |
| 新增频谱 | x=48..591, y=120..235 | FFT 1024 / 48K，青色L、黄色R频谱 |
| 原时域面板 | x=48..591, y=238..415 | 保留原256点双声道波形、增益和触发逻辑 |
| 原底部OSD | 保持原范围 | 滚动字幕 |

原波形仍是256个连续样本、每样本2像素，窗口5.33ms。频谱为128组，每组左2像素画L、右2像素画R；这是同一块1024点双声道样本计算的结果。时域和频域共用显示开关，但采样窗口长度和快照更新时刻不同，并不是同一瞬间的同一段波形。

## 2. 音频与FFT结构

```text
现有science_audio_i2s -> 现有I2S_receiver -> 原HDMI音频/ACR（不改）
                                     |-> 原audio_waveform_overlay
                                     |-> audio_fft1024
                                          1024对PCM缓存
                                          Hann窗 / 位倒序
                                          L FFT -> R FFT（复用同一蝶形资源）
                                          幅值近似 / 128组峰值 / 对数高度
                                          双缓冲，在VS提交给频谱绘图

视频：图片调整/淡入淡出 -> 原波形 -> 新频谱 -> 原OSD -> 原AXIS -> HDMI
KEY3：原防抖切换 -> 原波形帧锁存 -> 两个面板共用该帧状态
```

- 真正的radix-2 DIT FFT，不是固定图形、分段时域能量或伪FFT。1024点、10级、每声道5120次蝶形。
- 48kHz采样；频点间隔48000/1024=46.875Hz；每次连续采样窗口21.333ms。Hann窗会展宽主瓣，频点间隔不等于任意两个声源的可分辨距离。
- 在25MHz视频域旁路读取I2S解码后的24-bit立体声PCM，无新增时钟域，没有对HDMI音频的反压或暂停信号。
- FFT只取PCM高16位，低8位截断；周期Hann窗与旋转因子为16-bit Q1.15，乘积32-bit，旋转中间加减扩展33-bit。蝶形和输出前分别寄存，10级每级算术右移1位，最后整体缩放1/1024；输出饱和到有符号16位，不回卷。
- 左右声道共用一套16-bit复数工作RAM和四路乘法蝶形；另一路乘法处理Hann窗。整个工程最终DSP为22个（其中包括原有图像及音源资源）。
- 每块双声道计算约115714个视频时钟，即约4.63ms，仿真要求小于130000周期。计算及等待VS提交时跳过新到PCM，不把断续样本凑成一个块。每个已采集块内部1024对样本连续，HDMI音频始终继续。
- 采集21.33ms + 计算约4.63ms + 等待下一VS。640×480/25MHz实际帧率约59.52Hz，稳定运行频谱通常约每两视频帧更新一次；不是每21.33ms得到一幅新频谱。
- 样本捕获RAM和FFT工作RAM不复位，只有完整写入的数据才使用；系数ROM常量随综合初始化，不依赖下载电脑的绝对文件路径。

## 3. 频谱读法和数值边界

幅值采用 `abs(real)+abs(imag)`，再对频带内多个bin取最大值，不是精确平方根或功率求和。高度用近似log2映射，约每倍幅度6像素；小于4个FFT输出LSB不绘柱，最大66像素。未做窗增益、ADC标定或精确dBFS换算，不能作为声压计使用。

频率轴不是等间隔刻度，也不标称128点FFT。真实FFT为1024点；只把正频率bin 0..511（最高23953.125Hz）归并到128组显示，24K是右边界的近似标注。Nyquist bin512已计算但不显示。

| 显示组 | FFT bin | 每组合并 | 轴范围 |
|---|---|---|---|
| 0..31 | 0..31 | 1个 | 0..1.5kHz边界 |
| 32..63 | 32..95 | 2个 | 1.5..4.5kHz边界 |
| 64..95 | 96..223 | 4个 | 4.5..10.5kHz边界 |
| 96..127 | 224..511 | 9个 | 10.5..24kHz边界 |

这样既能观察220/330/440/660Hz教学音的移动，又保留较高次谐波。Hann泄漏和bin量化决定了峰不一定恰落在标称频率；方波高频在48kHz离散合成下还可能混叠，不能将所有可见峰解释成现实模拟方波的独立声源。

## 4. 无撕裂与显示保护

频谱L/R高度写入非显示bank，完整256个高度写完后等待VS，交换两路显示bank并确认。确认前FFT不采下一块，不会覆盖待显示结果。显示关闭时仍后台采集分析；打开后无需重新启动声音。

KEY3仍只有一个控制器。原波形在VS边界锁存开关，并把该状态输出给后续频谱；频谱收到延迟2拍的VS时，公共状态已经稳定，避免两块区域在临界按键时跨帧开关。

新频谱绘图与原波形各为2拍RGB/HS/VS/DE流水，共4拍。OSD及AXIS改接同一组最终时序，没有只延迟RGB而漏延迟DE/TLAST。原OSD最后叠加，Logo、数值和字幕不被面板遮挡。面板关闭时所有图像像素原样通过，仅增加固定延迟。

250ms没有有效PCM时，下一VS清除波形/频谱有效状态，不把旧快照当作实时声音；面板边框仍由KEY3决定。现有内部音源持续输出，包括静音PCM，因此正常教学状态不会触发缺音超时。

## 6. 实板验收

1. 保持现有TF卡四张BMP，下载本版bit。上电应仍显示教学图片，分析区域默认隐藏，原声音正常。
2. KEY3短按一次，应同时出现上频谱、下时域；再按一次，两者同时消失。长按、抖动和松开不应多切换。
3. 第一课：主峰随220/330/440/660Hz移动；第二课：频率位置基本不变、高度随幅度变化；第三课：方波/三角的谐波结构与正弦不同；第四课：青色/黄色频谱与L/R静音同步。
4. 同时反复操作KEY2下一课/亮度、KEY4轮播/对比度，确认图片、淡入淡出、字幕、Logo和音频不被破坏。
5. 轮播至少30分钟、反复KEY3至少100次、10次冷启动，检查无花屏、撕裂、声音卡顿和挂起。当前保持时间裕量较小，需保留长稳和温度变化验证。
6. 实板全部通过后再固化Flash并断电重启验收。本次没有写物理TF卡，没有下载硬件或烧写Flash。

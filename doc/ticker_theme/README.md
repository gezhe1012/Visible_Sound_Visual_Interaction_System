# 五页主题滚动字幕与PCM律动底栏

本版基于五页音乐工程`6051233`，仅修改原底部字幕样式和页面适配。用户的《滚动字幕提示词.md》及两张参考图为样式/文案依据；原图片、Logo、时间、BRI/CON、KEY1/2/3/4、转场、缩放、波形/FFT、48k音频和旋律行为不变。

## 使用

下载新版bit：`../../src/td_project/HDMI1.4b_Transmitter_v1.0_Runs/phy_1/HDMI1.4b_Transmitter_v1.0.bit`。

继续使用已有五图TF卡，无需更换BMP、WAV或写卡镜像。此次没有操作物理卡、下载开发板或烧写Flash；请先实板确认再固化。

## 五页文案

| 教学页 | 精确英文字幕 |
|---|---|
| 1 音高与频率 | EXPLORE PITCH AND FREQUENCY |
| 2 响度与幅度 | DISCOVER SOUND AMPLITUDE |
| 3 音色与波形 | EXPLORE TIMBRE AND HARMONICS |
| 4 左右声道 | EXPLORE STEREO SOUND |
| 5 当声音成为音乐 | FROM WAVEFORMS TO MUSIC |

全部使用大写英文字母和普通空格。主体青色，最后一个主题词暖金色。仍为2倍5×7像素字体，字形10×14、单元12像素，不用低清晰度缩小字体硬塞文案。

字幕依据**实际显示页面**`display_lesson_idx`，不是正在加载的图片。页编号在黑场提交，OSD收到同帧延迟后的VS时锁存新文案并清零滚动相位。不会在活动图像中途半行切换，也不会显示预加载下一页的提示。

## 640×480布局与效果

所有可见改动严格限定在原`y=430..463`这34行：

- 圆角深蓝底栏`x=8..631`，不增加高度、不挪动主图或分析面板。
- 左律动7条，`x=22..73`；右律动7条，`x=566..617`，条宽4像素，间距4像素，圆头。
- 中间字幕裁剪窗口`x=92..547`，宽456像素；文字仍位于`y=440..453`。
- 从右向左每视频帧移动1像素，约59.52像素/秒。两端32像素范围使用0..16共17级渐隐，从右侧背景色淡入、经中间、在左端逐渐消失。
- 不同长度文案使用各自循环长度。最长28字符、336像素，约5.65秒可完整进入窗口，能适应原约8秒自动轮播停留时间；切页立即在帧边界重新从右侧进入。

左右分别读取原I2S解码后的24-bit PCM，以每帧绝对峰值驱动。正负满幅（包括最小负数）使用无符号绝对值并饱和到显示范围，不会溢出回卷。帧级包络：上升约取差值1/4、下降约取差值1/16，保留8位小数并向上取整步进，因此静音最终能归零。

条高按声幅和缓慢移动的形状模板变化，每帧至多改变1像素，范围3..25像素；青色/金色亮度随平滑包络变化。左/右声道静音分别回落。没有PCM时不会持续显示伪造的高能量，只留下静止的最小短条。**两端为声幅装饰律动，不是第二套FFT频谱或精密仪表**；KEY3的真实时域/FFT分析面板没有改动。

## 修改范围与实现

- 新增`sound_theme_footer.v`，作为原OSD的底部样式子模块。
- `video_osd_overlay.v`仅移除旧通用ticker并接入底栏；原顶部Logo/时间/参数及其Alpha/字体逻辑原样保留。
- `top_tf_hdmi_audio.v`仅给OSD增加现有页面编号和现有PCM的只读连线，未改任何音源/HDMI端口。
- 新模块注册到`.al`和当前TD运行`.prj`；无新管脚、时钟、CDC或时序例外。
- 没有增加RGB流水线拍数，HS/VS/DE、AXIS行尾仍沿用原链路。
- 字符横坐标通过行内计数器推进，没有新增逐像素除法。渐隐/颜色用常量表，包络/条高使用加法和移位；本次DSP和BRAM数量均不增加。

## 实板验收

1. 继续用已有五页TF卡，下载新版bit；确认仅底栏变化，Logo、参数、图片和KEY3分析面板位置不变。
2. KEY2依次切五页，确认对应五句英文；开启自动轮播检查黑场换页后没有上页残留、长句能完整经过窗口。
3. 看右侧淡入、左侧消失；第二页音量变化和第四页声道静音应影响两侧条高/亮度，第五页末尾静音后律动慢慢回落。
4. 复查KEY2/KEY4长按、KEY3开关、完整旋律、图音同步；连续轮播至少30分钟并重复按键。
5. 全部确认后再固化Flash并做冷启动。本版工具已验证；物理显示效果、听感、长稳和Flash仍待实板验收。

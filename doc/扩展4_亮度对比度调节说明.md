# 扩展4：实时亮度、对比度调节与OSD信息

扩展3的图片缩放已由用户在开发板上确认正常。本版继续使用同一TF卡、HDMI_B和已有KEY1/KEY2管脚，无需增加外接器件。

## 操作

| 操作 | 效果 |
|---|---|
| 短按KEY1并松开 | 切换下一张图片，沿用现有转场 |
| 短按KEY2并松开 | 开启/关闭自动轮播 |
| 长按KEY1约0.8秒 | 亮度增加一档，继续按住每0.4秒再增加一档 |
| 长按KEY2约0.8秒 | 对比度增加一档，继续按住每0.4秒再增加一档 |
| 同时长按KEY1、KEY2约0.8秒 | 恢复亮度0、对比度100% |

按键含20 ms防抖，短按动作在松手并通过防抖后触发。长按不会额外触发切图/轮播；双键操作后需全部松开再进行下一次操作。

亮度按以下顺序循环，单位为8-bit RGB灰度级：

```text
0 → +16 → +32 → +48 → +64 → -64 → -48 → -32 → -16 → 0
```

对比度按以下顺序循环：

```text
100% → 125% → 150% → 50% → 75% → 100%
```

## 画面反馈

画面左上方Logo下方增加半透明参数面板，例如：

```text
BRI:+16 CON:125%
HOLD K1:BRI K2:CON
```

当前调节的参数以黄色显示，停止操作约2秒后恢复白色。双键恢复默认值时面板短暂显示绿色。Logo、时间戳和滚动字幕继续显示，OSD自身不受图片亮度和对比度影响。

## 实现

- `display_key_controls.v`：在25 MHz视频域同步按键，产生1 ms节拍并执行防抖、短/长按识别、连调和双键复位。
- 短按输出toggle事件，在`sd_card_bmp.v`中使用三级同步及异或检测传递到100 MHz SD域。默认参数`KEY_EVENT_MODE=0`保留原直接按键接口；当前顶层使用`KEY_EVENT_MODE=1`接收短按toggle。
- 请求参数在VS上升沿同时提交为显示参数，视频像素和OSD共用这一份帧快照；因此一帧不会中途突然改变参数。
- `video_picture_adjust.v`：三级流水线完成RGB中心化、定点乘法、亮度偏移与0～255饱和。
- 原图像数据先执行亮度/对比度处理，再执行转场亮度系数，最后叠加OSD；转场黑场不会被正亮度偏移抬高。
- RGB、HS、VS、DE统一延迟三级，再送OSD和AXI-Stream模块，保持像素、帧首和行边界对齐。

每个RGB通道的计算为：

```text
q = 对比度系数（2、3、4、5、6，对应50%、75%、100%、125%、150%）
out = clamp(floor(((in-128)*q+2)/4)+128+亮度, 0, 255)
```

中间数据采用有符号运算，乘法结果13位，偏移结果14位；右移前加2作四舍五入。亮度0、对比度100%时逐像素保持原值。结果超出范围会饱和到0或255，不会溢出回绕。

## 验证

运行本次仿真：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_display_controls.ps1
```

脚本会分别运行三个独立testbench，并同时检查退出状态、失败日志和通过标记：

- `tb_video_picture_adjust.sv`：45组亮度/对比度组合，每通道遍历256个输入值，检查独立整数计算结果、饱和、默认值、复位及三级时序。
- `tb_display_key_controls.sv`：检查抖动、短按、长按、连调、循环回绕、双键复位、交错松手、帧边界快照、操作提示超时和异步事件传递。
- `tb_osd_display_controls.sv`：对照45组文字数值，检查高亮、Alpha背景、提示字符及面板外像素，并生成640×480仿真画面。

另运行既有`run_commit.do`检查原有帧提交控制。工具仿真和构建结果不代表本版已经实机验收。

## 下载后检查

1. 下载`src/td_project/HDMI1.4b_Transmitter_v1.0_Runs/phy_1/HDMI1.4b_Transmitter_v1.0.bit`，先观察默认`BRI:+00 CON:100%`。
2. 短按KEY1切图、短按KEY2切换轮播，确认动作均只发生一次。
3. 长按KEY1观察画面整体变亮、数值逐档变化；继续按住越过+64后会循环到-64。
4. 长按KEY2观察反差变化，并核对050%、075%、100%、125%、150%五档数值。
5. 同时长按两键恢复默认值，分别松开两键，确认没有误切图或误切轮播。
6. 在调节后切图，确认参数持续有效，缩放、转场、字幕和HDMI音频仍正常。
7. 本版上板确认后再固化Flash；参数在复位/断电后恢复默认值，不写入非易失存储器。

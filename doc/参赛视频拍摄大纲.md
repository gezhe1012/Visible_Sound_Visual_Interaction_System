# 参赛视频拍摄大纲：看得见的声音——FPGA声学科普与双屏交互展示终端

本大纲依据项目内《赛题解析一.pptx》第5、6、21页及当前集成源码、最新Logo版说明整理。按用户明确的“三分钟以内”约束，成片目标为2分55秒（175秒），留5秒导出余量；片头、片尾和所有转场均计入总时长。

策划主线：用实拍证明基础要求，再逐项展示五项扩展，最后突出双屏、实时人声与科普应用。每一项都尽量形成“操作或声音变化→屏幕响应→一句解释”的完整镜头。

## 一、版本与拍前准备

- 当前集成版本入口：`src/td_project/HDMI1.4b_Transmitter_v1.0.al`；最新图形Logo版说明和bit位于`doc/logo_overlay/`，bit为`HDMI_anlogic_logo.bit`。拍摄前确认实际使用的版本与之对应，并完成固化和整机试拍。
- 全片使用同一个已固化设计，涵盖图片、字幕、转场、缩放、参数调节、音频分析、双屏与麦克风。赛题要求不能通过换不同镜像分别演示功能。
- 场景布置：HX4S20C开发板、装好五张教学BMP的TF卡、INMP441、两台显示器。HDMI_B接教学主屏并负责音频；HDMI_A接分析副屏。主屏使用自带扬声器或其音频输出连接音箱。
- 冷启动使用独立USB电源供电；让镜头看清没有PC下载连接，同时完整记录断电、上电、首图与声音恢复。不要把按复位键当作断电启动。
- 图片源尺寸依次为640×480、800×600、1024×768、1280×960、960×720，均为24-bit非压缩BMP。前五页从TF卡加载，第六页LIVE VOICE背景由逻辑生成，不需要第六张BMP。
- 备好屏幕录制与现场声音两条素材。片头可有配乐，测试音、声道、旋律和麦克风演示段关闭背景音乐。麦克风页HDMI输出静音，保留拍摄设备录下的现场讲话声。
- 拍摄屏幕和亮度调节时锁定相机曝光、白平衡与对焦；先试拍检查屏幕条纹，确保BRI/CON与频谱文字清楚可辨。

## 三、演示人员按键速查（按开发板丝印）

旧文档和HDL中的`key1/key2`不等于当前板上KEY1/KEY2。现场口播与字幕统一使用下表。

| 物理按键 | 操作 | 当前功能 |
|---|---|---|
| KEY1 | 按下 | 系统复位，回第一页，主屏分析面板恢复隐藏 |
| KEY2 | 短按并松开 | 下一页，1→2→3→4→5→6→1 |
| KEY2 | 长按约0.8秒 | 亮度增加一档；持续按住每约0.4秒再调一档 |
| KEY3 | 短按 | 同时显示/隐藏主屏时域波形和FFT；副屏分析继续运行 |
| KEY4 | 短按并松开 | 开关自动轮播 |
| KEY4 | 长按约0.8秒 | 对比度增加一档；持续按住循环调节 |
| KEY2＋KEY4 | 同时长按约0.8秒 | 恢复亮度0、对比度100% |

亮度循环：0、+16、+32、+48、+64、−64、−48、−32、−16、0。

对比度循环：100%、125%、150%、50%、75%、100%。

各教学页精讲时关闭自动轮播。可先拍整轮自动演示，再复位并逐页拍细节。KEY3开关状态会随正常切页保留；第一次精讲前确认面板已开启。

## 四、五项扩展各自留下哪一条证据

| 扩展项 | 最有说服力的镜头 | 配套说明 |
|---|---|---|
| 图层与字幕 | 图片、Logo、动态计时、半透明参数面板和滚动字幕同屏 | 动态内容在FPGA内生成；Logo为不透明原色，面板保留Alpha混合 |
| 转场 | 按键/自动触发的一次完整淡出、换页和淡入，原速连续拍 | 两帧缓存，新图写完整后在黑场/帧边界提交；本版不是两张图片直接交叉溶解 |
| 缩放 | 非640×480源文件属性→板上固定640×480画面 | 双线性插值。当前采用铺满输出，非4:3素材会改变比例；现有五张4:3图片足以展示不同尺寸缩放 |
| 参数调节 | 按键、图像、BRI/CON数值同步变化并恢复 | 相机锁曝光，画面变化才易判断 |
| 音频可视化 | 音高、幅度、音色或现场人声改变时，分析画面同步变化 | 主屏真实PCM波形＋1024点FFT，副屏真实历史/专题分析；底栏律动条只是幅值装饰，不当作第二套FFT |

## 五、三分钟版口播提示

开场：“看得见的声音：基于安路FPGA的双屏声学科普终端。”

冷启动：“系统固化在HX4S20C上，无需电脑下载，上电自动运行。”

切图：“从TF卡读取BMP，经SDRAM双缓冲输出HDMI，支持手动切换、自动轮播和淡入淡出。”

图层、缩放、参数三段各一句：“动态图层支持透明叠加与滚动字幕。”“不同尺寸图片经双线性插值适配显示。”“按键实时调节亮度、对比度，参数同步显示。”

音高、幅度：“频率改变，波形变密、谱峰移动。”“频率不变，幅度改变。”

音色：“正弦、三角和方波的谐波结构不同，双屏同步呈现。”说完留出至少一个完整声音变化周期。

声道：“左右声道分别驱动XY坐标，直观看见声道关系。”说完保留原声。

音乐：“FPGA实时合成原创旋律。”随后完整保留8秒音乐，不覆盖口播。

人声：“现在采集现场声音。”随后现场说“让声音被看见”，再发持续元音；旁白暂停，让现场声音和响应清楚对应。

结尾：“让声音可听、可看、可参与。”其余完成项和应用价值由字幕承担。

技术指标、模块名称和要求编号主要交给字幕，避免全片连续解说；字幕随对应画面出现，单屏只保留一个重点。

以上“固化上电”“现场响应”等口播在相应实机操作确认后使用。

## 六、现场取材顺序与补拍清单

为了减少反复接线和切换机位，取材可按下列顺序，剪辑再按第二节组织：

1. 先核对固化版本、五张TF素材、主副屏接线及所有按键；完成一次整段彩排。
2. 固定全景机位，连续拍一条“冷启动→六页手动演示→六页自动轮播”的完整素材。启动后手动打开主屏分析面板，避免面板默认隐藏。
3. 固定屏幕近景，逐页补拍：音高、幅度、三波形音色、左右声道、完整旋律、现场人声。每页留足一个完整变化周期，片头片尾各多留几秒。
4. 单独补拍按键与屏幕同框的参数调节、恢复默认、KEY3关闭/开启。短按与长按动作分别拍清楚。
5. 补拍TF卡、板卡型号、麦克风和HDMI接口特写，以及源BMP属性、当前版本工程框图与工具报告。
6. 拍摄连续运行素材和测试记录。若已做30分钟轮播、100次按键或多次冷启动，保留实际起止时间和结果；尚未做则不要写成已通过。
7. 录制口播，剪辑时仅在不影响听辨的部分加入配乐。保留一份无剪辑整机演示，方便核对功能来自同一最终设计。

至少保住四条原速连续镜头：冷启动、按键切图与转场、自动轮播、声音变化与分析响应。后期字幕可解释指标，但不能用后期动画替代系统输出。

## 七、表述边界与版本依据

- 主屏输出固定640×480。不同源图片分辨率不能表述成输出了不同HDMI分辨率，更不能宣称1080p/4K。
- 音频合成发生在FPGA内，项目中的试听WAV不是从TF卡实时解码播放；现有扫描器也不应表述为完整通用FAT文件系统。
- 1024点FFT、48kHz采样的频点间隔为46.875Hz；人声页放大横轴没有提高真实频率分辨率。
- 第六页是单麦分析。最新副屏人声页已经隐藏音符和PK频率数字，不要按旧截图讲解这些读数，也不要称其为语音识别或精密调音器。
- 图片转场淡出到黑场再淡入是设计效果；拍摄重点是变化平滑、没有未写完的新帧或异常花屏。
- 软件仿真预览、TD正时序裕量、历史版本的板级确认，均不能替代当前固化版本的实机验收。稳定性数据以本次实际记录为准。
- 如展示资源与时序，请采用`doc/logo_overlay/README.md`及相匹配的报告：LUT 15,250/19,600，BRAM 63/64，DSP 25/29，PLL 3/4；全局建立裕量+0.101ns、保持裕量+0.004ns，STA覆盖率96.38%。字幕宜写“当前约束下工具时序检查通过”，不写“100%全路径验证”。

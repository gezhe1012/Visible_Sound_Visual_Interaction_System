# 扩展5：双声道PCM音频波形叠加

本版按工程skill中“先完成音频波形，再视需要升级频谱”的路线实现扩展5。使用现有24-bit PCM音频数据绘制实时双声道时域波形，不是固定装饰图，也不是FFT频谱。扩展4已由用户于2026-10-25确认现象正确、初步完成。

## 下载后应该看到什么

- 仍用原TF卡、HDMI_B及现有KEY1/KEY2，不增加引脚或接线。
- 画面下半部出现半透明示波器面板，上方青色`L`为左声道，下方黄色`R`为右声道。
- 每条曲线显示256个连续PCM采样，每个采样占2个水平像素；标称48 kHz时，512像素横轴对应约5.33 ms。
- 现有测试音是C4～C5循环的方波，不是正弦波。因此曲线预期为方波，随音阶升高，一个窗口内的周期数增加；左右声道数据相同，曲线应基本一致。
- 当前测试音幅度固定，故音高变化主要表现为波形疏密变化，不应期待振幅随音阶显著变化。
- 缩放、图片轮播、转场、Logo、时钟、滚动字幕及亮度/对比度控制保留。波形与OSD均在图片亮度/对比度、淡入淡出之后叠加，切图黑场时可视化仍继续。

原按键操作不变：短按KEY1下一张，短按KEY2开关自动轮播；长按KEY1调亮度，长按KEY2调对比度；同时长按两键恢复默认。

## 数据通路与原理

```text
原I2S测试音 → 原I2S_receiver → audio_valid + 24-bit L/R PCM
                              ├→ 原ACR/HDMI音频通路（保持不变）
                              └→ 256采样波形采集 → 双缓冲帧快照

SDRAM图片 → 亮度/对比度 → 淡入淡出 → 波形叠加 → 原OSD → AXI-Stream → HDMI
```

### 同步与采集

`I2S_receiver`已在25 MHz `video_clk`中对I2S信号做同步采样，并输出同域PCM。本版只在该域的`audio_valid`有效时旁路读取PCM，不直接读取音频时钟域的多位数据，不增加新的异步数据通路，不改发生器、接收器、ACR及HDMI音频接口。

优先等待左声道由负到非负的过零沿作为触发点，再连续采集256个双声道采样。无过零沿时，等待256个有效采样后自动触发，因此静音和直流输入也能更新，不会永久等待。

### 映射、定点及饱和

每个通道将有符号24-bit PCM算术右移16位，再饱和至[-31,+31]：

```text
amplitude = clamp(floor(signed_pcm / 65536), -31, +31)
level = 31 - amplitude                 // 0..62，6位无符号
left_y = 255 + level                   // 中心线y=286
right_y = 339 + level                  // 中心线y=370
```

该增益只影响可视化，不改变送往HDMI的PCM音量。输入超过显示范围时曲线削顶，不会回绕。相邻采样之间绘制垂直连接段，使方波跳变连续可见。

### 双缓冲及视频延迟

两组256×24-bit RAM交替采集、显示。每个RAM字保存左右声道各自的当前值和前值（4×6位），渲染只需一个同步读端口。显示银行始终不被写入；采集满一组后冻结，等待VS上升沿交换银行，保证一帧内曲线不撕裂。上电未完成首次采集时不读取未初始化RAM作为曲线。

同步RAM读取和RGB合成使用两拍流水线，RGB、HS、VS、DE统一延迟两拍。既有OSD与AXI-Stream均改接延迟后的时序，未新增厂商IP或改变帧缓存接口。连同扩展4，图像处理路径共增加5拍视频延迟。

面板背景采用12/16黑色Alpha叠加；L/R文字、曲线和网格不受图片亮度调节影响。连续约250 ms未收到有效PCM后，在下一帧隐藏旧曲线，L/R标记变红；有效静音PCM则显示中心平线。数据恢复后重新采集并在帧边界恢复曲线。

## 上板验收顺序

1. 下载新版bit至FPGA，暂不覆盖Flash稳定版；接原HDMI_B、TF卡和可播放HDMI声音的显示设备。
2. 确认图片、Logo、时间、参数面板正常；下方L/R出现曲线，不应遮挡底部滚动字幕。
3. 听原循环音阶，观察方波疏密随音高变化；左右声道曲线应基本一致，不能一直固定成与音高无关的装饰线。
4. 短按切图和开关轮播、长按调亮度/对比度、双键恢复默认，确认曲线持续更新，声音不断续，图片无明显花屏或错位。
5. 自动轮播至少30分钟，检查波形不撕裂、不冻结，音频无持续爆音，并检查冷启动。通过后再按原工程流程固化Flash。

当前只有工具验证结论；开发板波形、HDMI音频实际效果及长稳运行须由实机确认。

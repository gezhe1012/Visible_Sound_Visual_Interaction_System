# 人声页精简读数与 FFT 聚焦版

基于 `bf35426`，本轮仅修改两个显示模块：`audio_spectrum_overlay.v` 和 `secondary_audio_renderer.v`。麦克风采集、上一版自适应噪声门/增益、FFT 运算、HDMI 音频、按键、帧缓存、时钟与约束均未修改。

## 画面变更

- 只在第六页移除副屏音符/八度（例如 A5）、PK 峰值频率数字及 HZ 单位，静音时的横杠占位也不显示。不以新文字填充空位；MIC / MONO、48K / 1024、瀑布、历史轨迹及所有位置保留。
- 只在第六页把主屏 FFT 横轴从 0–4.5 kHz 改为约 100–2000 Hz，刻度为 0.1K、1K、2K；频谱框大小、波形区与其他图层不动。
- 使用 1024 点、48 kHz FFT 的第 2–43 个频点，中心频率实际为 93.75–2015.625 Hz。将 42 个频点槽位均匀展开到原 512 像素；32 号频点以上继续复用原来每两点取最大值的存储，不新增 FFT 或缓存，不能把横向放大理解为提高真实频率分辨率（仍为 46.875 Hz）。
- 这是人声主要低中频区域的显示聚焦，不代表完整语音带宽，也不是新增音频带通滤波或语音分离。频带边缘仍可能显示窗函数泄漏，时域波形继续反映原有门控后的全带宽样本。
- 副屏瀑布图范围仍是 0–4.5 kHz。只删除用户指定的数值显示，没有删除后台特征计算或历史数据，历史轨迹保持原行为。
- 前五页教学图片及双屏内容、Logo、字幕、亮度/对比度、自动轮播、全部物理按键与引脚保持原样。KEY3 仍同时显示/隐藏时域和 FFT，不影响后台结果更新。

## 下载与回退

下载本目录 `HDMI_live_voice_focus.bit`。先用临时下载验证，第六页应无 A5/PK/HZ，主屏 FFT 应为 0.1K–2K；正常讲话及持续元音应有明显响应，安静时仍沿用上一版噪声门。再测试 KEY3 开/关、前五页图片与声音、手动/自动切页和显示参数控制。

前一版镜像完整保留在 `../noise_reduced/`，初始麦克风版保留在上一级目录；本轮不覆盖它们。TF 卡图片无须替换。

工程入口：`src/td_project/HDMI1.4b_Transmitter_v1.0.al`。本目录 `INMP441_live_voice_project.zip` 包含集成 RTL/IP、工程入口、运行目录配置、测试源、当前 bit 和证据；不包含旧版 bit，也不替代原 TF 卡素材。

## 复现入口

在 `tests` 工作目录用 ModelSim 执行 `run_voice_focus.do`、`run_voice_display.do` 和 `run_voice_compat.do`；在工程根目录执行 `tests/run_voice.ps1`、`tests/run_fft.ps1`、`tests/run_display_controls.ps1`、`tests/run_secondary_checks.ps1`。

重新生成 bit：`complete-hx4s20c-hdmi-project/scripts/verify_project.ps1 -RunImplementation`；结构与管脚检查：`tests/check_voice_structure.ps1 -CheckRouted`。继续执行既有 ROM/CDC 网表审计后，使用 `tests/capture_voice_evidence.ps1 -VoiceFocus` 收集本轮 `voice_focus_*.log`，再使用预览/打包脚本的 `--voice-focus` 参数输出本目录。

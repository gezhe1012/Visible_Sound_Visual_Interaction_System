# INMP441 实时人声输入：第六页

后续静音底噪优化版见 [noise_reduced/README.md](noise_reduced/README.md)，新版 bit 与证据单独放在该子目录。本页及同目录 bit 保留原始 `b2feea7` 交付记录；当前源码已包含后续优化，请勿将这里旧版的前端参数与新版混用。

本版在 `6e58891` 上集成，原五张 BMP 无须更换。第六页由逻辑生成背景，复用原有波形、1024 点 FFT 和副屏瀑布图。工具证据见同目录 `build_evidence.json`、`routed_timing.txt` 与 `test_logs/`。新功能的实机麦克风/双屏验收尚待用户完成；RTL 预览不是上板照片。

最终工具结果：LUT 14985/19600（76.45%），寄存器8331，BRAM 63/64、DSP 27/29、PLL 3/4；建立裕量 +0.138 ns、保持裕量 +0.011 ns，STA覆盖96.38%。并未增加 BRAM、DSP 或 PLL。原厂 SDRAM 时钟局部布线等既有警告保留在构建记录中，不将 STA 覆盖率表述为100%。

`INMP441_live_voice_project.zip` 包含集成的 RTL、IP、工程入口、当前运行目录配置、测试源、bit和证据。原 TF 卡镜像及旧测试使用的外部 WAV/图片素材继续使用原工程版本；本次新增人声测试不依赖这些外部素材。仿真预览见 `dual_screen_rtl.png`。

## 接线与使用

按用户已接好的接线实施：

| 模块 | 开发板接口 | FPGA 球位 | 方向 |
|---|---|---|---|
| VDD | J1-29 | 3.3V 电源 | 电源 |
| GND | J1-30 | 公共地 | 电源 |
| SCK | J1-31 / GPIOA_26 | M15 | FPGA 输出 |
| WS | J1-32 / GPIOA_27 | L16 | FPGA 输出 |
| SD | J1-33 / GPIOA_28 | N16 | FPGA 输入，内部下拉 |
| L/R | J1-12 | GND | 左声道选择 |

1. 断电核对接线，保留原 TF 卡五张教学图片。
2. 将本目录中验时序通过的 `HDMI_live_voice.bit` 下载到开发板。最初先使用易恢复的临时下载验证，固化沿用原工具流程。
3. 用物理 KEY2 短按切页：第 1→2→3→4→5→6→1。第五页完整乐曲和自动轮播等待保持原有行为；第六页自动轮播停留仍采用原来的 8 秒。
4. 第六页标题为 `LIVE VOICE`。原有 KEY3 状态继续生效，若面板隐藏，按 KEY3 同时开启波形和 FFT；再按同时隐藏。KEY1 仍复位，KEY2 长按仍调亮度，KEY4 短按仍控制自动轮播、长按仍调对比度。
5. 对着麦克风讲话或持续发元音，先从靠近模块的自然说话距离测试。主屏青色 W 为有符号波形，金色 A 为同一声道的绝对幅度曲线；频谱 M 表示单麦，横轴聚焦 0–4.5 kHz。
6. 副屏保持现有布局，第六页显示 `MIC / MONO`、频谱瀑布和趋势轨迹。`PK~` 是主频峰近似值，音符提示和轨迹不是准确的人声基频/音准评测；单麦模式不启用立体声 XY。

第六页不回放麦克风：HDMI 仍运行原音频接口和 ACR，发送静音 PCM；返回第 1–5 页恢复对应 DDS 教学声音。原图像、Logo、时间、字幕、转场及亮度/对比度链路继续使用。

## 采集与可视化

- 新增 `inmp441_i2s_rx.v`，在原视频 25 MHz 域运行；该时钟来自板载 50 MHz 与原视频 PLL。保持全部 PLL/IP 配置不变。
- 有理数累加器每秒发出平均 6.144M 个边沿使能，生成平均 3.072 MHz SCK；64 个 SCK 一帧、WS 平均 48 kHz，24 位有符号、MSB 在 WS 边沿后一位开始。
- SCK 半周期为 160/200 ns，完整周期为 320/360 ns；有效样本间隔为 520/521 个视频周期。分数时钟存在明确的周期抖动，并非低抖动音频晶振；本用途为声音分析，已用延迟外部从设备模型验证协议和平均采样率，实物边沿仍需示波器/逻辑分析仪确认。
- INMP441 规定 SCK 周期至少 312 ns、SCK 高低至少 50 ns、最高 3.2 MHz、每帧 64 SCK。参考官方 [INMP441 datasheet](https://product.tdk.com/system/files/dam/doc/product/sw_piezo/mic/mems-mic/data_sheet/inmp441.pdf)。复位后等待 4096 帧（约 85.33 ms）再发布采样。
- SD 经过两级采样寄存器进入视频域；只有外部 SD 到第一级输入采样端点设置例外，级间路径仍参与时序。SCK/WS 为输出波形，从未作为内部逻辑时钟。
- `voice_analysis_source.v` 执行 Q24.8 去直流（约 7.5 Hz）、1024 样本块级噪声门与 8–128 倍移位增益，再按 24 位有符号饱和。固定阈值与增益范围需结合现场噪声实测；LISTEN/VOICE/LIMIT 是数据状态，不代表检测到了物理模块插入。
- 前五页的分析数据直接透传原 DDS PCM。仅进入/退出第六页时复位分析捕获和 FFT，丢弃旧源的未完成窗口；原 I2S 接收器、DDS 算术、HDMI音频接口、ACR和厂商加密源未改。
- 保留 1024 点、48 kHz、46.875 Hz 频率间隔与原 RAM 深度；256 点波形覆盖约 5.33 ms。副屏频谱沿用 0–1.5 kHz / 1.5–4.5 kHz 两段映射，适合观察元音及中低频谐波，但不会覆盖全部辅音高频细节。
- 同一个麦克风样本复制到现有左右 FFT 槽，仅作兼容适配。主屏不会把它标成双麦，副屏第六页不显示伪立体声相位。
- 第六页直接复用当前已提交的 SDRAM 背景缓存，真正的底色由 RGB 逻辑生成，沿用原帧边界转场握手；返回第一页后再按原双缓存流程读图。扫描目标仍是五张，不要求第六张 BMP，不增加 SDRAM 帧缓存。

### 时序收敛调整

初次实现的 SD 初始化控制路径出现 -0.432 ns 建立裕量。现将 `sd_init_done` 在控制器内部注册一级后送入缩放器，只增加启动就绪资格的一拍，不延迟图像数据。该调整后重新通过真实 FAT32 五图读取、六页播放器、内存带宽和旋律回归。

原视频域读请求会保持到应答，内存侧已有 `read_req_d0→d1→d2` 三级同步，状态机仅消费 d2。本版在综合阶段只绑定 d0 的一个逻辑数据脚，增加精确 CDC 入口例外；d0→d1、d1→d2、应答、地址和数据路径仍参与原时序检查。此逻辑端点随物理打包保留；最终网表另行审计实际 MI/Q 连线：d0 独占 REG0，d1/d2 合并在另一个双寄存器切片中，不能把所有 `.mi` 名称当作有效 D 端点。约束不使用整组视频/内存时钟例外。完整约束变更、匹配与连线审计及最终时序均保留在工程与构建证据中。

建议实机顺序：先五页基线与按键→第六页静音/说话/持续发声→返回五页确认音频及图片→自动轮播→重复冷启动和长稳。若第六页始终无响应，先核对 SD/SCK/WS 顺序、L/R 确实接地与模块声孔，再测 SCK、WS及 SD 数据；不要把“采样时钟正常”当成“麦克风已输出真实声音”。

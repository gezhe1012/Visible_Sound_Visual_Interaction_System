## HDMI_A 硬件依据

核对原始资料：

- `G:/BaiduNetdiskDownload/9_康芯开发板使用手册及实验平台/HX4S20开发板手册-HDL版2410.pdf`，第 8 页明确 HDMI_A 可作为输入或输出，并给出引脚表；第 11～12 页 HDMI_B 引脚与原工程一致。
- `G:/BaiduNetdiskDownload/3_原理图/开发板原理图/7_HDMI.pdf`，第 1 页：两路 TMDS 直连 FPGA，经耦合电容及 ESD；接口供电和 DDC 电平转换电路均已查看。不是从参考框图推断管脚。
- 官方 `APUG092_HDMI1.4b_Transmitter_V1.0.docx`：复用原 IP，像素时钟与串行时钟为 1:5，外部 AXIS 每行连续输入，SOF 为首像素、TLAST 为行末像素。

| 信号 | HDMI_A P / N | 说明 |
|---|---|---|
| TMDS CLK | K1 / J1 | P 引脚设置 LVDS33，工具分配配对 N |
| TMDS D0 | F5 / F4 | 同上 |
| TMDS D1 | E3 / E4 | 同上 |
| TMDS D2 | B3 / D3 | 同上 |
| DDC SCL / SDA | P1 / R1 | 独立于 HDMI_B 的 P2 / R2 |

CEC、HPD 本版没有新接入逻辑；绿色角标表示发送 IP 的**视频输入锁定**，不是 HDMI 电缆热插拔检测，也不是 EDID 兼容性证明。

## 保持主屏不变的方式

- 顶层只增加 HDMI_A 端口和 `secondary_hdmi_tx` 实例。原 HDMI_B 发射器、五页图像、时域/FFT、音源、KEY1/2/3/4、OSD、底栏、缩放、转场和 SDRAM 连线没有改动。
- 不复制主屏图像/音频处理链路、不复制 FFT；本阶段测试画面甚至不读取 PCM/FFT，也不操作原 FFT 的确认握手。
- 复用现有 25 MHz 像素、125 MHz 串行时钟，以及原复位与启动 EDID 触发；没有新 PLL、新跨时钟域或时序例外，主屏 40 MHz SDRAM 时钟不变。
- 第二个**原厂 HDMI IP + 原厂 PHY**实例独立发送 RGB，音频 valid/ACR valid 固定为 0。主屏的 I2S、PCM、ACR 和 HDMI 音频仍只按原路径工作。
- 副屏不增加完整帧缓存，也不使用 SDRAM。只用计数器和小字体组合逻辑生成测试图。
- 页面来自主屏已提交的 `display_lesson_idx`，同属视频时钟域，在副屏帧起点锁存；主屏换页不会中途改变副屏页码。

## 必须先做的实板验证

1. 主屏仍接 HDMI_B，五图 TF 卡不动；10 寸副屏接 HDMI_A，副屏使用自己的合规电源。
2. 先下载阶段 1 bit 到 FPGA 运行测试，**暂不固化 Flash**。
3. 应同时看到：主屏仍为原教学画面，副屏为独立 DISPLAY LINK TEST 校验画面，底部游标持续移动。
4. 主屏手动切五页，副屏 PAGE 1～5 应在下一帧更新；KEY3 仍只控制主屏原时域/FFT，主屏亮度、对比度、自动轮播、完整旋律和字幕均正常。
5. 保持两屏连接，检查无花屏、错位、持续闪烁、声音中断；最好提供两屏同时入镜的照片或短视频，并说明副屏型号。若副屏无信号，先确认其支持 640×480 约 59.52 Hz，不改变主屏时钟去盲目适配。
6. 将结果反馈后才进入真实 FFT 瀑布图、音高轨迹阶段；若阶段 1 不可靠，先回到稳定 bit 排查，不继续堆功能。

## 真实数据结构

### 第三页 HARMONICS

- 对现有 FFT 的左声道 bin 0～127 保存 17-bit 原始幅值，约 272 字节，实际映射为 1 BRAM；不复制 FFT，不读取 DDS 设定频率。
- 收到现有特征模块的有效“同一 FFT 块分析完成”事件后，以该块的实测频率定位 H1～H5。有效频率限制为 100～1000 Hz，因此 H5 近邻最高不超过 bin 108，落在缓存内。
- `k_h=floor((8*h*f_hz+187)/375)`，即以 46.875 Hz/bin 四舍五入定位；每次取 `k_h-1,k_h,k_h+1` 的最大真实幅值。
- 一组串行读取器和窄位宽算术依次计算五根柱，柱高为 `min(38,floor(38*Hn/H1))`。H1 至少达到 32，且原 FFT 估计有效时才显示；所有柱共享 H1 参考。
- 采用常数减法定位及 38 次分数累加完成归一化，不在像素路径做除法，也不使用五套并行除法器。处理后只在副屏帧起点发布。
- 与早期讨论的“上一帧定位”不同，最终使用小缓存实现了**同块频率、同块幅值**，避免跨音符错配。换页时丢弃未完成结果，不批量复位 RAM。
- 幅值沿用 `abs(Re)+abs(Im)`，不是精确功率、THD 或校准 dB。H1 用暖金色、H2～H5 用青色，不伪造固定谐波比例。现有第三页约 440 Hz 的正弦、三角、方波会自然呈现不同结果。

### 第四页 STEREO XY

- 每个 `audio_valid` 同时取真实 `audio_left/audio_right`：左声道映射 X，右声道映射 Y，正值向右/向上。不从 FFT 幅度伪造相位。
- 对 24-bit 有符号 PCM 取算术高 8 位（相当于除以 65536），对称裁剪至 -31～31，映射到 64×64 点阵。相对满量程/半屏尺度为固定增益 4，不使用独立自动增益破坏左右幅值关系。
- 两个 64×64 的 1-bit 平面合计 8192 bit，实际为 1 BRAM；写入面先逐地址清零，再采集 512 对样本，只有完整平面可在视频帧起点成为显示面。
- 原始采样窗口约 10.67 ms；显示按原视频帧率更新。写入面不触碰显示面，像素只查 RAM，不逐像素并行比较几百个采样点。
- 显示区域为 x=432～559、y=192～319，逻辑点放大为 2×2 像素；淡色十字轴，少量 L/R 标签，无新增中文、固定相位角或装饰椭圆。
- 第四页原音源不变：单左为水平点迹、单右为竖直点迹；双声道 L≈440 Hz、R≈660 Hz，因此应呈约 2:3 李萨如图，而不是同频正交圆。原 DDS 相位/量化和采样窗会影响实际点迹，不承诺完全静止的理想曲线。
- 超过原无 PCM 超时后在帧起点隐藏；有有效静音采样时显示中心点，区分“真实静音”和“无有效 PCM”。

### 布局保护

第三页只修改 y=384～463 的底部区域；第四页只修改 y=136～375 的专题区域。第四页瀑布的历史仍为 96 列、64 频带，只将每列 5 像素改为 3 像素，频带和时间长度不变。

第一、二、五页全部像素、第三页其他区域和第四页顶部/底部，均与 `8aea081` 的独立基准渲染器逐像素比较。主屏 KEY3 开关只控制原主屏时域/FFT，副屏不新增控制开关。KEY1/2/4、音频播放、完整旋律等待和 TF 卡素材均不变。

## 综合与时序策略

新模块只观察已有 PCM/FFT，不增加返回握手，原 FFT 的 `result_ack` 仍只由主屏控制。50 MHz 板载时钟、25/125 MHz 视频、100 MHz SD、40 MHz SDRAM 及原 SDC/ADC 均不变，没有新 PLL 或时序例外。

首轮并行谐波候选导致切片密度过高，TD 跳过保持时间修复，因此未交付；之后改成小 RAM 和串行算术。曾尝试的预布线保持修复在本器件不受支持，最终不采用。临时同步字体 ROM 也已撤回，保留已验收的原字形和两拍输出链路。

最终通过 `tests/secondary_enhanced_synthesis.tcl` 调用官方默认流程，并采用已确认有效的 `gate opt_area high`、`gate pack_effort high` 面积映射选项，让标准布局布线流程有空间修复保持时间。这是综合映射配置，不是放宽时序约束。重新构建请使用本工程的 `verify_project.ps1 -RunImplementation`；若直接在 GUI 新建运行，需对应设置映射参数，不能假定默认策略等同于本次交付。

## 数据和存储结构

现有 I2S 解码 PCM → 原 1024 点定点 FFT（Hann 窗、左右时分复用）→ 被动原始幅值/原频带结果输出 → 副屏特征与历史 RAM → 独立 RGB/AXIS → 已验证的 HDMI_A 原厂发送器和 PHY。

- 不复制 FFT。`audio_fft1024.v` 只新增 `capture_start/bin_valid/bin_channel/bin_number/bin_magnitude` 观察输出，原输入、运算状态、幅值/高度和 `result_ack` 协议未改。ACK 仍只由主屏控制。
- 原始幅值为 `abs(Re)+abs(Im)`，不宣称精确功率、dB SPL 或 THD。瀑布图复用原 FFT 的对数幅值高度，压缩为 16 档；左右同频带取最大值。
- 频率视图选择原 128 频带中的低 64 带：前 32 带每带 1 bin，后 32 带每带 2 bin；覆盖 bin 0～95，最高中心 4453.125 Hz，上沿约 4.5 kHz。纵轴**分段线性，不是全程等距 Hz**。主屏原 0～24 kHz 频谱不变。
- 显示 96 个历史时间列，每列 64×4 bit；物理环形缓存 128 列，共 4 KiB，额外 32 列作为写入保护区。另用 128×8 bit 音高轨迹 RAM。实际综合 RAM 映射见资源报告。
- 已完成的左右数据及音高摘要就绪后，64 个时钟将新列写入不可见区；仅在副屏帧起点发布 head/count/摘要。复位/换页不批量清 RAM，而以有效列计数屏蔽旧值。验证包括 128 列地址回卷和显示中禁止写可见列。
- 单窗口 1024/48000 = **21.333 ms**，但原 FFT 还需运算并等待主屏帧确认。真实节拍回归测得稳态约 **33.6 ms/列（两个视频帧）**，96 列显示约 **3.23 秒**时间跨度。不是每 4 窗更新，也不是 8.19 秒。
- 保持原 25/125 MHz 视频时钟、40 MHz SDRAM、100 MHz SD 时钟和所有原时序约束；无新 PLL、无新跨域、无新 SDRAM 帧缓存。副屏仅视频，音频仍走原主屏 HDMI 链路。

## 音高估计的含义与限制

1. 对每个声道的 bin 2～511 搜索最大幅值，排除 DC/极低频；记录峰值及两侧邻点。
2. 峰值至少 32，且不低于所搜索频谱总和的 1/64，才作为有效窄带候选。这是启发式静音/宽带噪声门限，不是精确 SNR 测量。
3. 三点抛物线插值得到 Q8 频点偏移，限制在 ±0.5 bin；串行除法器处理，避免复制大运算核心。
4. 按 48000/1024 = **46.875 Hz/bin** 换算 Hz；只对前后相差不超过 10 Hz 的连续有效读数做两帧平滑，普通换音不跨音符平均。
5. 用固定十二平均律阈值表映射 C2～B6 音符，不读取 DDS 目标频率表。音高轨迹以 100～1000 Hz 实际频率线性映射到 48 像素，超界裁剪；不是按音符编号画等间距台阶。
6. 左声道有效时优先显示左声道，否则使用有效右声道；FFT/L 或 FFT/R 明确标识来源，轨迹青色为 L、暖金为 R。不对双音做虚假的“唯一基频”判断。
7. 静音/无效候选时显示横线；无 PCM 有效脉冲超过 250 ms 后清当前读数及幅值。历史区保留已经发生的数据，静音 PCM 正常到达时继续写暗列。

屏幕 `F0~` 是**单主峰音高估计**，适用于本工程的单音教学和单旋律；强谐波压过基频、缺失基频、复调音乐或复杂噪声可能发生八度/音符误判。本版没有实现谐波乘积谱、YIN 或多音分离，也没有承诺任意音源的调音器精度。数字按 Hz 显示不代表 1 Hz 频率分辨率。

PK/AVG 基于每 1024 个有效 PCM 采样的有符号 16 位高位绝对值；峰值和平均绝对幅值分别缩放到 224 像素条，考虑了 -32768 边界。不是 RMS/响度计。

TD 导出网表脚本路径应使用 `/`，例如 `td_commands_prompt.exe tests/export_fft_netlist.tcl`，随后运行 `python tests/verify_fft_rom_netlist.py`。最终使用 `tests/capture_secondary_audio_evidence.ps1` 收集本轮通过日志、bit、时序、资源与源码哈希；它拒绝失败/过期 bit 和旧网表。不要在当前分析版上运行旧的阶段 1 打包脚本覆盖接口验证产物。

独立参考用已有五个未经修改的 48 kHz/24-bit WAV 驱动完整 FFT + 特征 RAM + 渲染 RTL，共核对 480 个频谱块、30,720 个 4-bit 历史单元、480 组音高摘要和 PCM 幅值统计，再输出五页真实光栅。音乐预览选原 WAV 的 4.5 秒处起始片段，其他页面从起始采样开始。该预览测试加速了采样/帧提交以缩短仿真；没有将其描述为实时吞吐验证。

独立的 `run_secondary_live.ps1` 使用真实 25 MHz、48 kHz 时钟使能、原 DDS 和 I2S 编解码，仅缩短每种教学音/音符持续时间；主屏 VS 独立确认 FFT，检查连续采样、真实 FFT 周期、五页发布、音高/声道状态和旋律换音。缓存单测另覆盖 132 块跨环回卷、页间废弃、帧发布、满负幅值、静音超时与复位；光栅单测独立核对 921,600 像素及两拍 AXIS 首末标志。

`check_secondary_structure.ps1` 删除新增 HDMI_A 和被动 FFT 连线后逐字比较原主屏顶层，并验证原 FFT 状态/运算/握手、原音频/波形/OSD/字幕/SDRAM/IP/时钟源码与 `a0bd824` 一致；最终全局 setup/hold 不通过时拒绝交付。原厂加密 HDMI IP 无公开 ModelSim 行为模型，不将 RGB 仿真说成完整 TMDS/显示器电气仿真。

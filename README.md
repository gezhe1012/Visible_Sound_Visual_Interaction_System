# 看得见的声音

基于安路 HX4S20C FPGA 的双屏声学科普系统。主屏展示课程、播放教学音并叠加实时波形与频谱，副屏同步呈现频谱历史、音高轨迹、谐波及声道关系，让声音从“听得到”变成“看得懂”。

**当前版本已完成六页功能、综合与布局布线、烧录及上板测试。**

![实时人声双屏预览](doc/logo_overlay/dual_screen_rtl.png)


## 六页内容

| 页面 | 内容 | 观察重点 |
| --- | --- | --- |
| 1 · 音高与频率 | 220、330、440、660 Hz 正弦音 | 频率与音高的对应关系 |
| 2 · 响度与幅度 | 440 Hz 下切换相对幅度 | 波形、峰值与平均绝对幅值 |
| 3 · 音色与波形 | 正弦、三角、方波 | H1～H5 谐波及音色差异 |
| 4 · 左右声道 | 单左、单右、双声道 | L/R 幅值与真实 XY 点迹 |
| 5 · 当声音成为音乐 | 120 BPM、17 音符、8 秒原创旋律 | 波形、频谱与音高随旋律变化 |
| 6 · 实时人声 | INMP441 单声道采集 | 现场声音的即时波形与频谱历史 |

## 设计亮点

- **共享分析驱动双屏**：复用同源 PCM 与一个 1024 点定点 FFT，主屏负责教学交互，副屏负责数据解释。
- **特征来自实际信号**：H1～H5 以同一 FFT 块的实测主频定位；XY 直接使用成对 L/R 采样生成。
- **人声接入原分析链路**：独立标准 I2S 接收，配合去直流、自适应噪声门及增益控制；第六页仅分析，HDMI 音频保持静音。
- **兼顾显示与资源**：加载时双线性缩放、SDRAM 双帧转场、环形历史缓存及帧边界发布，支持动态字幕、Alpha 叠加、亮度/对比度调节。六页主屏统一使用安路官方图形 Logo。

## 硬件与操作

硬件：HX4S20C 开发板、TF 卡、两台 HDMI 显示器及 INMP441。

- **HDMI_B**：主屏，输出教学画面及前五页音频。
- **HDMI_A**：副屏，输出同步分析画面。
- **INMP441**：VDD 接 J1-29（3.3 V），GND 接 J1-30，L/R 接地；SCK 接 M15/J1-31，WS 接 L16/J1-32，SD 接 N16/J1-33。

| 按键 | 操作 |
| --- | --- |
| KEY1 | 复位 |
| KEY2 | 短按下一页，长按调节亮度 |
| KEY3 | 同时显示或隐藏主屏波形与 FFT 面板 |
| KEY4 | 短按切换自动轮播，长按调节对比度 |
| KEY2 + KEY4 | 同时长按，恢复默认显示参数 |

## 运行工程

1. 使用 **Anlogic TD 6.2** 打开 [工程入口](src/td_project/HDMI1.4b_Transmitter_v1.0.al)。当前归档构建版本为 TD 6.2.168116，器件为 EG4S20BG256。
2. 按[素材说明](doc/science_kiosk/第五页音乐扩展说明.md)准备 FAT32 TF 卡，将 [五张 BMP](doc/science_kiosk/bmp/) 按课程顺序连续存放。第六页背景由逻辑生成，无需新增 BMP；音频由 FPGA 合成，无需复制 WAV。
3. 连接双屏与麦克风，下载当前 [六页统一 Logo 版 bit](doc/logo_overlay/HDMI_anlogic_logo.bit)，或由工程重新构建后下载。
4. 使用 KEY2 切换六页，KEY3 开启分析面板，KEY4 开启自动轮播。

两路视频均为 **640×480、约 59.52 Hz**；音频采样率 **48 kHz、24 bit**，FFT 频点间隔 **46.875 Hz**。人声页主屏频谱聚焦约 **100～2000 Hz**，副屏保留约 **0～4.5 kHz** 历史视图。
